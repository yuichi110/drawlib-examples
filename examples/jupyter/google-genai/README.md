# Google GenAI SDK Cookbook (`type = "jupyter"`)

Bilingual (`en` / `ja`) interactive Jupyter & Google Colab notebook series demonstrating the unified `google-genai` Python SDK across **Google AI Studio**, **Vertex AI**, **Streaming & `ThinkingConfig`**, **Pydantic Structured Outputs**, and **Multi-Turn Chat & Function Calling**, richly illustrated with **Drawlib**.

## Notebook Chapters (`en/` & `ja/`)

1. `01_ai_studio_quickstart.md` — Hello World with Google AI Studio (API Key & GCP Project Billing)
2. `02_vertex_ai_quickstart.md` — Hello World with Vertex AI (IAM Auth & Enterprise Migration)
3. `03_streaming_and_thinking.md` — Streaming Delivery & `ThinkingConfig` Reasoning Control
4. `04_structured_outputs.md` — Type-Safe Structured Outputs with Pydantic (`response_schema`)
5. `05_chat_and_function_calling.md` — Multi-Turn Chat Sessions & Python Function Calling

## Quick Commands

```bash
# Build .ipynb notebooks + HTML preview into _build/jupyter/
./examples/jupyter/google-genai/build.sh

# Preview locally in browser
./examples/jupyter/google-genai/serve.sh
```
